# 米哈游 IP 知识小问答（MihoyoQs）

基于 **Vue 3 + Vite** 的米哈游知识问答网页，米游社蓝白风格，支持 **白天/夜间模式** 与 **中文 / English / 日本語** 三语切换（含题库内容翻译）。顶栏图标为自绘的"米"字星芒描改 SVG。帮助你了解并考察米哈游公司与旗下作品（不含《未定事件簿》）的内容知识。

## 运行

```bash
npm install
npm run dev                            # 开发模式，默认 http://localhost:5173
npm run build                          # 生产构建，输出到 dist/
npm run preview                        # 预览生产构建
node scripts/validate-questions.mjs    # 题库结构校验（选项数/答案下标/重复题）
node scripts/validate-i18n.mjs         # 翻译校验（覆盖数/选项完整性/答案存在性）
```

## 功能

- **477 道题**：选择题 + 判断题，每题附带解析；选择题选项每次取题随机打乱，答案位置无规律
- **六大分类**（每类 50 题以上）：
  | 分类 | 题数 | 内容 |
  |---|---|---|
  | 米哈游与米游社 | 69 | 公司历程、社区功能、作品年表与奖项 |
  | 原神 | 121 | 七国七元素、元素反应、角色、玩法系统 |
  | 崩坏3 | 74 | 女武神、律者、组织、装备与玩法 |
  | 崩坏：星穹铁道 | 78 | 星穹列车、星神命途、角色与玩法 |
  | 绝区零 | 69 | 新艾利都、空洞、绳匠、阵营与角色 |
  | 崩坏学园2 | 66 | 长空市、千羽学园、自机角色与系列沿革 |
- **白天/夜间模式**：跟随系统偏好，可手动切换，localStorage 记忆
- **三语切换**：中文 / English / 日本語，界面与 477 题题干、选项、解析全部翻译，localStorage 记忆
- 自由勾选出题范围、选择题量（10 / 15 / 20 / 30 / 全部），题目随机打乱
- 答题即时反馈（对错配色 + 解析）、进度条、连对计数
- 结算页：正确率圆环、称号评级（三语）、分类战绩、错题回顾、再来一局

## 多语言说明

- 界面文案在 `src/i18n/ui.js`（含称号评级与分类名）。
- 题目翻译按 `分类id-序号` 存于 `src/i18n/q.en.*.js` / `q.ja.*.js`；选择题翻译以 **正确答案文本 `c`** 反查下标，从机制上杜绝语序错位。
- 运行 `node scripts/validate-i18n.mjs` 可校验翻译覆盖与答案有效性（当前 954 条全部通过）。

```
    │   └── ResultScreen.vue   # 结算页（成绩/错题回顾）
    ├── i18n/
    │   ├── index.js           # 语言/主题状态、题目翻译与乱序缓存
    │   ├── ui.js              # 三语界面文案 + 分类名
    │   ├── q.en.js (+4 分卷)  # 英文题库翻译
    │   └── q.ja.js (+4 分卷)  # 日文题库翻译

```

### 追加题目

在 `src/data/qs.*.js` 中按格式追加（新题自动获得稳定 id）：

```js
{ t: 'c', q: '题干', o: ['A', 'B', 'C', 'D'], a: 0, e: '解析' }, // 选择题，a 为正确项下标
{ t: 'j', q: '题干', a: true, e: '解析' }                        // 判断题
```

改完运行两个校验脚本；如需同步三语，在 `src/i18n/q.en.*.js` / `q.ja.*.js` 补充对应 id 的翻译（未翻译的题目自动回退中文）。
